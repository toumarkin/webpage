## 5. Цельная фигура + лист из 9 лиц
Я дала тело в Т-позе без головы (`screens/04-body-tpose.png`) и лист лиц 3×3 (`screens/03-faces-sheet.png`).
ИИ нарезал тело на шарниры, а лица сделал сменными по прокрутке: нейтральное → взгляд в сторону → испуг → глаза закрыты → взгляд вверх → улыбка.

Итерации по моим скриншотам:
- обрезались волосы, и рука ломалась на краю рукава (`screens/05-feedback-*.png`) → исправлено;
- локти и колени: попытка с круглыми суставами — «стало хуже» (`screens/06-feedback-joints-worse.png`).

**Вывод:** Т-поза — плохой исходник для поворотов рук: плечо и рукав нарисованы горизонтально и ломаются при любом повороте.
