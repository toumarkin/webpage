# Nataliya — Design / Code

Личная страница-«удостоверение личности»: перспективный грид (модернистский порядок) при прокрутке трескается, гнётся, разлетается и собирается заново по своим правилам. В центре — нарисованная фигура, которая меняет позу и выражение лица на каждом этапе.

Шесть этапов: **Order → Descent → Distortion → Break → Fragments → Own rules**.

## Как запустить у себя

Сайт статический: HTML, CSS, JS и картинки, без сборки.
Из-за ES-модулей открывать `index.html` двойным кликом нельзя, нужен любой локальный сервер:

```bash
cd nataliya-site
python3 -m http.server 8000
# или: npx serve .
```

Затем откройте http://localhost:8000

## Как выложить на сервер

Скопируйте папку целиком в корень сайта (или в подпапку): `index.html`, `css/`, `js/`, `assets/`.
Папки `process/` и `tools/` нужны для репозитория и документации, на сервер их можно не класть.
Никаких зависимостей и сборки нет: Three.js лежит в `js/vendor/`.

Единственный внешний ресурс — шрифты Google Fonts (Archivo, JetBrains Mono). Без интернета они заменятся системными.

## Структура

```
index.html               разметка: сцена, подписи, блок с текстом позиции
css/style.css            стили и цветовые переменные
js/config.js             ← ВСЕ НАСТРОЙКИ: тексты кадров, порядок поз и лиц, цвета, записки
js/main.js               рендер, камера, прокрутка → шкала времени, подписи
js/world.js              комната-грид и её разрушение (шейдер изгиба, разлёт панелей, имя, записки)
js/figure.js             фигура: смена поз и лиц, наклоны, дыхание
js/util.js               мелкие функции (random, плавные переходы)
js/vendor/               Three.js 0.149 (лицензия MIT)
assets/figure/poses/     6 поз тела (выровнены по ремню и низу джинсов)
assets/figure/faces/     9 лиц из листа 3×3
assets/figure/figure.json  размеры и точки шеи для каждой позы и лица
assets/notes/            сюда — ваши сканы/записки (см. NOTES в config.js)
assets/scenes/           сюда — будущие сцены
process/                 документация процесса для задания
tools/                   Python-скрипты, которыми готовились картинки (для справки)
```

## Частые правки

| Что | Где |
|---|---|
| Тексты под номерами кадров | `STAGES` в `js/config.js` |
| Какая поза на каком кадре | `POSE_KEYS` в `js/config.js` |
| Какое лицо на каком кадре | `FACE_KEYS` в `js/config.js` |
| Цвета панелей в финале | `COLORS.accents` в `js/config.js` |
| Свои сканы вместо серых записок | файлы в `assets/notes/` + список `NOTES` в `js/config.js` |
| Длина прокрутки (скорость разрушения) | `#scroll-track { height }` в `css/style.css` |
| Текст позиции (300–500 слов) | блок `<main id="statement">` в `index.html` |

### Добавить новую позу
1. Нарисуйте фигуру в той же манере, на прозрачном фоне, в том же масштабе.
2. Выровняйте её с остальными (скрипт `tools/align_poses.py` или вручную по ремню и низу джинсов), сохраните в `assets/figure/poses/имя.webp`.
3. Добавьте её в `assets/figure/figure.json` (`poses` → `src` и `neck`, точка шеи в пикселях) и в `POSE_KEYS`.
